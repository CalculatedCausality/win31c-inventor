Help / keyboard input

Wait for Windows Program Manager to finish booting. Mount latest reads out/disk.img into drive A: using PCjs's original file upload form. Close CAD before remounting after a build. In Program Manager, Launch CAD sends Alt+F, R, then A:\CAD.EXE and Enter with slow emulated keystrokes. Select Program Manager first; this action cannot detect the active guest window. CAD starts with an empty document; the house belongs under Demos, not startup.


Click the display or Capture mouse to lock the physical mouse to the guest cursor. PCjs uses a relative serial mouse, so capture prevents host/guest pointer offset. Press Escape to release it; click Capture mouse again to resume. Keyboard-only Focus display does not click or capture. CPU speed cycles PCjs's native speed setting. Reset restarts the guest. Reload starts a fresh machine; guest disk writes stay in emulator memory, never in the repository. First boot downloads PCjs/ROM/Windows resources to ignored debug/.cache/; network access is needed until cached.
